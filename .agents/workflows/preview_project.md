# Preview Project Workflow

This workflow describes how to start the development server to preview the project.

## Steps

1. **Start Development Server**
   Run the following command to start the Next.js development server:
   ```bash
   npm run dev
   ```

2. **Access the Preview**
   Once the server is ready, open your browser to the URL displayed in the terminal (usually http://localhost:3000 or http://localhost:9002).
